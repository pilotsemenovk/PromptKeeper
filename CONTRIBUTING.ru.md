# Участие в разработке PromptKeeper

Спасибо за интерес к участию в разработке! Этот гайд поможет вам начать.

## Как помочь

### Сообщение об ошибках
1. Проверьте, не была ли ошибка уже зарегистрирована в Issues
2. Напишите чёткое описание с шагами воспроизведения
3. Укажите версию браузера, ОС и любые сообщения об ошибках
4. Приложите скриншоты, если это уместно

### Предложение функций
1. Опишите функцию и почему она будет полезна
2. Приведите примеры того, как она будет работать
3. Обсудите потенциальные компромиссы или проблемы

### Отправка кода

1. **Сделайте fork репозитория**
   ```bash
   git clone https://github.com/pilotsemenovk/PromptKeeper.git
   cd PromptKeeper
   ```

2. **Создайте ветку функции**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Внесите изменения**
   - Редактируйте файлы расширения в `extension/` или веб-приложение в `webapp/`
   - Тщательно протестируйте перед отправкой
   - Делайте коммиты сфокусированными и информативными

4. **Протестируйте изменения**
   - Загрузите расширение в браузер (`chrome://extensions/`)
   - Протестируйте веб-приложение
   - Проверьте работу импорта/экспорта
   - Тестируйте с разными ИИ-сервисами

5. **Коммит и push**
   ```bash
   git add .
   git commit -m "Add: краткое описание изменений"
   git push origin feature/your-feature-name
   ```

6. **Откройте Pull Request**
   - Опишите, что вы изменили и почему
   - Ссылайтесь на связанные Issues
   - Будьте готовы ответить на замечания

## Стиль кода

- Используйте `const` и `let` (избегайте `var`)
- Используйте описательные названия функций: `callOpenRouter()`, `parsePromptText()`
- Старайтесь держать функции компактными (до 50 строк)
- Добавляйте комментарии только для "почему" (неочевидная логика), не "что"
- Используйте точки с запятой последовательно
- Отступы из 2 пробелов

## Примечания к архитектуре

### Расширение (Manifest V3)
- **Service Worker** (`background.js`): Управляет всеми фоновыми операциями, хранилищем, сообщениями
- **Content Scripts** (`content.js`): Внедряются на ИИ-сайты, лёгкие и быстрые
- **Popup** (`popup.html/js`): Основной UI с тремя вкладками (Промпты, Инструменты, Импорт)
- **Параметры** (`options.html`): Страница настроек API ключа

### Веб-приложение (`webapp/index.html`)
- Однофайловое приложение с inline CSS и JavaScript
- Использует IndexedDB для сохранения данных
- Может импортировать/экспортировать JSON для синхронизации с расширением

## Формат данных

Оба — расширение и веб-приложение — используют одинаковый формат:

**Промпты:**
```json
{
  "id": "unique-id",
  "title": "Название промпта",
  "content": "Полный текст промпта...",
  "tags": ["тег1", "тег2"],
  "created": 1234567890000
}
```

**Инструменты:**
```json
{
  "id": "unique-id",
  "name": "Название ИИ инструмента",
  "url": "https://example.com",
  "description": "Что делает этот инструмент",
  "tags": ["категория", "функция"]
}
```

## Тестирование

Перед отправкой PR:
1. Протестируйте сохранение промптов с разных ИИ-сервисов
2. Протестируйте функцию поиска (текстовый и ИИ-поиск)
3. Протестируйте импорт/экспорт с примерами данных
4. Убедитесь, что промпты и инструменты сохраняются после перезагрузки браузера
5. Протестируйте функцию контекстного меню (правый клик)
