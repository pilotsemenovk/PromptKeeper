# Гайд по разработке

Этот документ содержит техническую информацию для разработчиков, работающих над PromptKeeper.

## Структура проекта

```
PromptKeeper/
├── extension/
│   ├── manifest.json
│   ├── background.js          # Service Worker
│   ├── content.js             # Контентный скрипт для ИИ-сайтов
│   ├── content.css            # Стили контентного скрипта
│   ├── popup.html             # UI popup расширения
│   ├── popup.js               # Логика popup и состояние
│   ├── popup.css              # Стили popup
│   ├── options.html           # Страница параметров
│   ├── icons/                 # Иконки расширения (16, 48, 128 px)
│   └── data/
│       ├── ai-tools.json      # Предзагруженные 240+ ИИ-инструментов
│       └── imported.json      # Предзагруженные 115+ промптов
└── webapp/
    ├── index.html             # Однофайловое веб-приложение
    └── imported.json          # Те же данные, что в расширении
```

## Ключевые понятия

### Manifest V3
Расширение использует стандарт Chrome Manifest V3, который:
- Требует Service Worker вместо background page
- Content scripts взаимодействуют через `chrome.runtime.sendMessage()`
- Запрещены встроенные скрипты (весь код в отдельных файлах)
- Строгая CSP (Content Security Policy)

### Архитектура хранилища

**Расширение:**
- Использует API `chrome.storage.local` для сохранения данных
- IndexedDB для больших наборов данных (если понадобится в будущем)
- Данные сохраняются после перезагрузки браузера

**Веб-приложение:**
- Использует IndexedDB браузера
- Полностью отдельная база от расширения
- Может экспортировать/импортировать JSON для синхронизации с расширением

### Передача сообщений

Расширение использует простой протокол сообщений между контентным скриптом, popup и service worker:

```javascript
// Из контентного скрипта в service worker:
chrome.runtime.sendMessage({
  action: "savePrompt",
  data: { title, content }
}, response => console.log(response));

// Service worker слушает:
chrome.runtime.onMessage.addListener((msg, sender, respond) => {
  if (msg.action === "savePrompt") {
    // Обработка и ответ
  }
});
```

## Интеграция API

### OpenRouter API

Все функции ИИ используют бесплатный уровень OpenRouter:

**Endpoint:** `https://openrouter.ai/api/v1/chat/completions`

**Аутентификация:**
```javascript
headers: {
  "Authorization": `Bearer sk-or-v1-...`,
  "HTTP-Referer": location.href,
  "X-Title": "PromptKeeper",
  "Content-Type": "application/json"
}
```

**Модели:**
- **Бесплатная модель:** `meta-llama/llama-3.3-70b-instruct:free`
- **Альтернативные модели:** На openrouter.ai/models

**Функции:**
1. **Поиск:** Найти похожие промпты по запросу
2. **Очистка:** Удалить метаданные Telegram из импортированных промптов
3. **Извлечение:** Определить промпты и инструменты в вставленном тексте

### Обработка ответов

API может вернуть ответы, обёрнутые в markdown блоки кода:
```javascript
let json = response;
// Попытка извлечь JSON если обёрнут в markdown
if (typeof response === 'string' && response.includes('```json')) {
  const match = response.match(/```json\n([\s\S]*?)\n```/);
  if (match) json = match[1];
}
return JSON.parse(json);
```

## Локальный рабочий процесс разработки

### 1. Установка расширения

```bash
# В Chrome/Yandex/Edge:
# 1. Перейдите на страницу расширений
# 2. Включите "Режим разработчика"
# 3. Нажмите "Загрузить распакованное расширение"
# 4. Выберите папку extension/
```

### 2. Тестирование внедрения контентного скрипта

Откройте любой поддерживаемый ИИ-сайт (ChatGPT, Claude и т.д.) и проверьте:
- Кнопка "Сохранить промпт" в нижнем правом углу
- Или правый клик → "PromptKeeper: Сохранить выделение как промпт"

### 3. Тестирование веб-приложения

```bash
# Откройте в браузере (протокол file:// работает)
open webapp/index.html
# Или используйте локальный HTTP сервер
python3 -m http.server 8000
# Затем откройте http://localhost:8000/webapp/
```

### 4. Отладка

**Отладка расширения:**
- Откройте DevTools в popup: Правый клик на popup → "Inspect"
- Консоль service worker: На странице детальной информации расширения → "Service worker"
- Консоль контентного скрипта: Обычная консоль страницы (Ctrl+Shift+J)

**Отладка веб-приложения:**
- Стандартный браузерный DevTools (F12)
- IndexedDB доступна в вкладке Storage

### 5. Тестовые данные

Используйте предзагруженные JSON файлы:
- `extension/data/imported.json` — 115+ промптов
- `extension/data/ai-tools.json` — 240+ инструментов

Или создайте тестовые данные:
```json
{
  "prompts": [
    {
      "id": "test-1",
      "title": "Тестовый промпт",
      "content": "Это тест",
      "tags": ["тест"],
      "created": 1234567890000
    }
  ],
  "tools": []
}
```

## Обычные задачи

### Добавить поддержку нового ИИ-сайта

1. Обновите `manifest.json` content script matches:
```json
"matches": [
  "*://example-ai.com/*",
  // ... другие сайты
]
```

2. Обновите `content.js` для определения интерфейса чата:
```javascript
function detectChatContent() {
  // Найти последнее сообщение или область ввода
  // Извлечь текстовое содержимое
  // Вернуть { title, content }
}
```

### Добавить новую ИИ-функцию

1. Создайте функцию в service worker, которая вызывает OpenRouter
2. Вызовите из popup/webapp с `chrome.runtime.sendMessage()`
3. Обработайте JSON ответ и случаи ошибок
4. Обновите UI для отображения результатов

### Обновить предзагруженные данные

1. Отредактируйте `extension/data/imported.json` или `ai-tools.json`
2. Убедитесь в правильности формата JSON
3. Протестируйте импорт с веб-приложением
4. Веб-приложение объединит с существующими данными

## Рекомендации по производительности

- **Контентный скрипт** запускается на каждом посещении сайта → держите его лёгким
- **Service worker** сохраняется между сеансами → аккуратно работайте с состоянием
- **Storage API** имеет ограничения (~10МБ на расширение) → сжимайте при необходимости
- **OpenRouter API** имеет ограничения по скорости → добавьте дедупликацию запросов

## Соображения безопасности

- **API ключ:** Никогда не раскрывайте в клиентском коде; держите в хранилище расширения
- **CORS:** Используйте `/api/` endpoint OpenRouter (они обрабатывают CORS)
- **CSP:** Расширение имеет строгую CSP; нет `eval()`, нет встроенных скриптов
- **Хранилище:** IndexedDB имеет политику same-origin; веб-приложение не может получить доступ к данным расширения
