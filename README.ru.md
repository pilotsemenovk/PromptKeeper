# PromptKeeper

Расширение для браузера + локальное веб-приложение для сохранения, организации и поиска промптов с помощью ИИ.

**Основные возможности:**
- 💾 Сохраняйте промпты с 15+ ИИ-сервисов (ChatGPT, Claude, Gemini, DeepSeek, Grok и др.)
- 🤖 Семантический поиск на основе Llama 3.3 70B
- 📚 Предзагруженная база 115+ промптов и 240+ ИИ-инструментов
- 🔍 Интеллектуальная категоризация и дедупликация промптов
- 📤 Импорт/экспорт JSON для резервной копии и синхронизации
- 🌐 Полностью локально (браузерное IndexedDB) — регистрация не требуется
- 🆓 Бесплатный уровень с щедрыми ограничениями

## Быстрый старт

### Вариант 1: Расширение для браузера (рекомендуется)

**Для Яндекс.Браузера, Chrome или Edge:**

1. Клонируйте или скачайте этот репозиторий
2. Откройте страницу расширений вашего браузера:
   - **Яндекс.Браузер:** `browser://extensions/`
   - **Chrome:** `chrome://extensions/`
   - **Edge:** `edge://extensions/`
3. Включите **Режим разработчика** (переключатель в правом верхнем углу)
4. Нажмите **"Загрузить распакованное расширение"** и выберите папку `extension/`
5. Иконка PromptKeeper появится в панели расширений

**Настройка доступа к ИИ (бесплатно):**

1. Перейдите на **https://openrouter.ai/keys** и зарегистрируйтесь (вход через Google, карта не требуется)
2. Нажмите **"Create Key"** и скопируйте ваш API ключ (начинается с `sk-or-v1-...`)
3. Нажмите правой кнопкой на иконку PromptKeeper → **Параметры** → вставьте ключ → **Сохранить**

> **Модель:** Бесплатный уровень использует `meta-llama/llama-3.3-70b-instruct` — отлично работает с русским языком, щедрые ограничения

**Как пользоваться расширением:**

- **Сохранение промптов:** На ChatGPT, Claude, Gemini и других нажмите кнопку **"💾 Сохранить промпт"** (внизу справа) или используйте контекстное меню
- **Просмотр и поиск:** Нажмите на иконку расширения для доступа к:
  - **Вкладка "Промпты":** Просмотр, поиск, редактирование, удаление
  - **Вкладка "ИИ инструменты":** Предзагруженная база из 240+ ИИ-сервисов
  - **Вкладка "Импорт":** Вставьте переписку из Telegram → ИИ автоматически извлечет промпты и инструменты

### Вариант 2: Веб-приложение

Просто откройте `webapp/index.html` в браузере. Используется то же локальное IndexedDB хранилище.

**Первый запуск:**
1. Нажмите ⚙️ (настройки) → добавьте ваш OpenRouter API ключ
2. Управляйте промптами и инструментами локально
3. Экспортируйте/импортируйте JSON для синхронизации с расширением

## Архитектура

### Расширение для браузера (Manifest V3)
- **Service Worker:** Управляет хранилищем, маршрутизацией сообщений и контекстным меню
- **Content Scripts:** Внедряют кнопку "Сохранить промпт" на сайты ИИ-сервисов
- **Popup UI:** Трёхвкладочный интерфейс для просмотра, поиска и импорта
- **Хранилище:** Chrome storage API + IndexedDB для сохранения данных

### Веб-приложение
- **Один HTML файл:** Включает все CSS и JavaScript
- **IndexedDB:** Локальная база браузера для автономного доступа
- **File System Access API:** Может читать/писать JSON для импорта/экспорта
- **OpenRouter API:** Семантический поиск через Llama 3.3 70B

### Поток данных
```
ИИ-сайт → Content Script → Service Worker → IndexedDB
                                    ↓
                            OpenRouter API
                             (ИИ функции)
                                    ↓
                        UI расширения / Веб-приложение
```

Промпты автоматически получают названия, извлеченные из содержимого. URLs в промптах становятся кликабельными.

## API и ограничения

**Бесплатный уровень OpenRouter:**
- Модель: `meta-llama/llama-3.3-70b-instruct:free`
- Ограничение: Варьируется в зависимости от времени суток
- Стоимость: Бесплатно
- Задержка: ~2-5 секунд
- Карта не требуется

Для более высоких ограничений или платных моделей измените `callOpenRouter()` в коде и выберите другую модель.

## Разработка

### Разработка расширения
- Редактируйте файлы в `extension/`
- Изменения в service worker требуют перезагрузки (обновите в `chrome://extensions/`)
- Изменения в UI popup или content script применяются при перезагрузке страницы

### Разработка веб-приложения
- Один файл: `webapp/index.html`
- Откройте в браузере с протоколом `file://` или локальным HTTP сервером
- Данные сохраняются в IndexedDB браузера
- Экспортируйте JSON для резервной копии

### Сборка и распространение
Для распространения:
1. Создайте zip папки `extension/`
2. Загрузите в Chrome Web Store или аналоги
3. Или распространяйте как распакованное расширение с инструкциями

## Конфиденциальность и безопасность

- ✅ **Нет хранилища на сервере:** Все промпты и инструменты хранятся локально в браузере
- ✅ **API ключ не покидает браузер:** Отправляется только на OpenRouter для ИИ-запросов
- ✅ **Без отслеживания:** Никакой аналитики или телеметрии
- ✅ **Открытый исходный код:** Полная прозрачность работы кода
- ⚠️ **Безопасность браузера:** Расширение имеет доступ ко всем сайтам (требуется для внедрения), но читает/пишет только в IndexedDB

## Решение проблем

**В: Расширение не появляется в браузере**
- Проверьте, включено ли оно в `chrome://extensions/` (или `browser://extensions/` в Яндексе)
- Попробуйте перезагрузить страницу расширений

**В: Ошибка "API ключ не установлен"**
- Откройте параметры расширения (нажмите правой кнопкой → Параметры)
- Вставьте ваш OpenRouter API ключ и сохраните
- Убедитесь, что ключ начинается с `sk-or-v1-`

**В: ИИ-поиск не работает**
- Проверьте, действителен ли ваш API ключ на https://openrouter.ai/
- Попробуйте более простой запрос
- Проверьте консоль браузера на ошибки

**В: Не удается импортировать JSON файл в веб-приложение**
- Убедитесь, что формат JSON совпадает с `data/imported.json`
- Попробуйте сначала экспортировать из расширения

**В: Промпты не синхронизируются между расширением и веб-приложением**
- Они используют отдельные базы (изоляция IndexedDB)
- Используйте экспорт/импорт JSON для ручной синхронизации
- Или используйте кнопку **"Загрузить базу из расширения"** в веб-приложении
